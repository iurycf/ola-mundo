# Olá Mundo

App de iPhone (Swift + SwiftUI) com um botão que mostra "Olá mundo" e vibra. É um projeto de estudo montado sem Mac: a cada envio para a branch `main`, o GitHub Actions gera o app sem assinatura.

- Código do app: `OlaMundo/`
- Configuração do projeto (XcodeGen): `project.yml`
- Montagem automática: `.github/workflows/montar-app.yml`
